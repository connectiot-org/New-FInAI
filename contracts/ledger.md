# Read-only imported ledger source 1.0.0

Trusted CLI only,5MiB,<=500 accounts,<=5000 journals/10000 lines; no large JSON proxy change. Import requires active scoped canImport and expectedVersion. Complete normalized JSON: schemaVersion1,sourceName,capturedAt,mappingId,basis:accrual|cash,currency ISO3,precision0..6,periodStart/periodEnd full months,completePostedRegister:true, accounts [{id,name,classification:cash|receivable|asset|liability|equity|revenue|expense,normal:debit|credit,openingDebit,openingCredit}], journals [{id,date,status:Posted|Draft,lines:[{id,accountId,debit,credit}]}]. Exact nonnegative integer minor-unit strings <=9007199254740991; no floats. Opening trial balance and every journal balance; duplicate IDs, unknown accounts, malformed/foreign dates, overflow, incomplete input rejected. Opening P&L balances, if present, remain source balances and are excluded from selected-month movements; opening balance applies immediately before periodStart. Journal dates within complete source period; drafts validated but excluded from calculation. Account normal sign explicit; revenue/liability/equity normal credit; cash/receivable/asset/expense normal debit. Unsupported contra classifications require a new reviewed mapping/version, never guessed.

Immutable snapshots hold normalized source/digest/actor/version/capture/import times and complete validated content in PostgreSQL. Identical current retry idempotent; stale/historical retry409; atomic source/audit. GET /ledger?entityId&month&snapshotId(optional latest) returns source metadata, mappingVerified boolean, deterministic exact balances/movements/metrics and <=500 account rows plus <=100 source journal records/page using offset/limit. All results echo currency/precision/source period/basis. Unapproved mappings expose raw accounts/journals only: metrics=null and no derived closing/movement account fields. Verified mappings expose deterministic calculations. Read grant required. Missing source explicit no_snapshot; out-of-coverage explicit unsupported. Source viewer supports real citations, never demo ledger links.

Closing account balance = opening debit-credit + posted movements through month end, displayed in account normal sign. Period revenue/expense excludes opening balances and includes only that month's posted movement; receipt debits cash and credits receivables, never revenue. Profit=revenue-expense. Assets include cash/receivable/asset; liabilities/equity use credit signs; retained period profits reconcile balance sheet for full source coverage. No cash flow/forecast/aging/FX/consolidation. Different currencies never combined. Comparisons use same complete immutable source covering both periods, otherwise unsupported.

Real statement/cash/revenue/expense/profit answers require mappingId@sha256(mapping fingerprint) in explicit server ASSISTANT_LEDGER_MAPPING_IDS, fingerprint binds accounting basis, currency, precision and sorted account ID/class/normal signs; maintained after finance approval outside source files. Imported mappingId is not proof of approval. Engineering tests may compute supplied synthetic fixture; that is not finance approval or target source verification. Preserve source values regardless of enabled statement mappings.
