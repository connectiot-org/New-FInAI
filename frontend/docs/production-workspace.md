# Private finance workspace

`/workspace` redirects to `/workspace/overview`; `/workspace/checklist` and `/workspace/subscriptions` reuse the existing saved modules. Unknown `/workspace/*` routes remain private not-found pages. `/` marketing and `/welcome`/existing financial demo stay separate and public. Nothing in private pages maps us/uk/demo personas to backend identity, renders a synthetic FinanceSnapshot, or invents balances.

Build with VITE_AUTH_MODE=session, VITE_API_BASE_URL=/api/v1, VITE_CHECKLIST_MODE=api and VITE_RECEIVABLES_MODE=api. All four are checked before private requests. Credentials/proxy/DB variables remain server-only per backend/RELEASE.md. One session gate encloses all three modules; nested gates inherit its context. Login/session responses are strictly decoded. Private state is in-memory/scoped and removed on logout/401; failed logout stays visibly failed. Entity/period/month selections remain module-specific and reauthorize through server discovery, not demo names/positions.

From frontend/: npm run typecheck, npm run lint, npm run build, npm run test:workspace (eight focused cases), npm run test:workspace:production (actual built proxy/session/isolated DB journey). Existing default/checklist/subscription/session/receivables suites remain and CI adds both workspace commands. Asset scanning includes artifacts/workspace-dist. No browser/DB setup bypass is used; system Chromium and prepared local PostgreSQL work in this environment. Synthetic captures live under ignored artifacts/workspace and artifacts/workspace-production at1440/390/320; never use real private customer records for test captures.

The production-build test imports synthetic A, authenticates, checks the real summary, persists tasks/subscriptions across refresh/restart, imports B, checks new balances/version, tests failed logout/expiry, and confirms no private browser storage. This is local evidence, not target deployment/production financial verification. See ../../context/production-workspace.md for route/action ownership and later slice/release gates.

Private extensions: `/workspace/receivables/invoices`, `/customers`, `/periods` read pinned immutable sources with bounded search/status/customer/issue-period pages, source history and exact CSV. Overview rows link only into these real routes. `/workspace/imports` reviews complete JSON registers (1 MiB browser limit); `/workspace/administration` controls existing members/entities/grants and safe audit. Navigation derives from validated `/workspace/context`; changed identity/revision remounts private modules, failed context refresh hides the body and session401 clears everything. No private source state is saved to financial browser storage. See backend/WORKSPACE.md for provisioning, expiry/retry, permissions, migration and target gates. Import confirmation is not financial approval.
