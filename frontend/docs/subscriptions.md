# Subscription renewals

Route: `/tools/subscriptions`. The page always uses backend records, fetched with the same authorized entity endpoint and existing administrative session/local identity as the checklist. Financial-demo roles/entity IDs and localStorage are not authorization or subscription storage. The new navigation item is under Manage. Search covers supplier/subscription names; status offers active/archived/all. Lists are ordered renewal date/id, 20 records/page. Add/edit uses the existing drawer, and archive/unarchive requires confirmation. Unknown/failed writes stay visible; conflicts require closing/reopening the current record. A failed creation retains its UUID for a safe identical retry rather than creating another record. Backend errors never fall back to fixtures.

Local setup: complete backend migrations/build, then from frontend run `npm ci` and `VITE_API_BASE_URL=http://127.0.0.1:3000/api/v1 npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`. No checklist demo flag is required for this API-only tool. Production uses `VITE_AUTH_MODE=session VITE_API_BASE_URL=/api/v1 npm run build` plus the existing server-only proxy/host configuration documented in backend/RELEASE.md. The public checklist demo remains unchanged; this tool shows visible backend failures when not connected/configured.

Date columns show separate server-calculated renewal and cancellation indicators. Today and the organisation timezone appear above the table; default timezone is UTC unless the administrator configures `ORGANISATION_TIMEZONES` on the backend. Archived rows show dates without indicators. Dates never assert that renewal, cancellation or charging happened. Users must manually edit dates; there are no reminders, recurring generation, uploads, email or paid API calls.

Checks: `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test:subscriptions`. The subscription browser suite starts an isolated migrated/seeded PostgreSQL schema and a real child API on 3002; it exercises CRUD, refresh/API restart, search/status/pagination, date indicators, validation, failed saves, conflicts, delayed entity responses, keyboard and mobile layout. Keep port 5173 free. The fixture drops only its unique synthetic schema. `npm run test:session` also exercises subscriptions through the existing production-build HTTPS/session/proxy harness.
